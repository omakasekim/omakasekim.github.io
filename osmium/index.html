Osmium

A context-mixing compressor for text, written in Rust and measured on the Hutter Prize data: the first gigabyte of English Wikipedia. One small program compresses and decompresses, and every number on this page is a verified round trip.

Against the Hutter Prize

The prize scores the compressed enwik9 plus the decompressor. The record listed on July 24, 2026 is 100,424,672 bytes (Vladimir Ivanov, fx2-cmix-T). Osmium's total is 168,311,575 bytes (archive plus the zipped decompressor), so it is not a contender: record entries run thousands of models, LSTM mixers and large preprocessing dictionaries over days of CPU time. Osmium is a compact, readable member of the same family that beats the general-purpose tools by a wide margin, and a base to build on.

How it works

  • Predict every bit. Twelve context models (byte orders 0–6 and 8, the current word, the last two and three words, word plus previous byte, and a wiki-markup context) each give a probability from hashed, cache-line-sized slots with a slow and a fast counter.
  • Long matches. A match model finds the last occurrence of the previous seven bytes and predicts that the text continues the same way, with confidence learned per match length.
  • Mix and refine. Three gated logistic mixers and a final mixer combine the predictions; three SSE stages correct the result in context.
  • Code. A binary arithmetic coder turns the probabilities into bits. Everything is integer arithmetic, so archives are identical on every machine and in the browser.
