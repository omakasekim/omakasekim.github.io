Silica

Global behavior from purely local rules, running live in your browser. Draw on the canvas. This page is a JavaScript port of the rules in Silica, which is written in Kotlin.

Presets
RLE Import / Export

What makes it work:

  • Life updates every cell at once with any Life-like B/S (or legacy S/B) rule, reading one buffer and writing another before swapping.
  • RLE imports and exports standard run-length encoded patterns with header rules, comments, 70-character line wrapping, and size limits matching Silica's Kotlin core.
  • Sand moves matter in place, scanning from the bottom up with the direction alternating each frame. A clock bit in each cell stops a particle moving twice in one frame.
  • Sleeping regions: a 16 by 16 chunk where nothing moved is skipped on the next frame, which the status line counts.
