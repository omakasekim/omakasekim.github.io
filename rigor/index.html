Rigor

An independent proof checker for Lean 4, written in safe Rust. It re-checks every definition and theorem that Lean exports, so a proof is trusted only if a second, small kernel agrees.

Try the real kernel

The same kernel and parser, compiled to WebAssembly, run below on Lean's Init.Prelude export (1,840 declarations; 570 KB download). Checking runs in a background worker on one thread. Tamper gives one theorem another theorem's proof; the kernel must refuse it.

How it stays trustworthy

  • Small, auditable kernel. Type inference, definitional equality and the inductive-type checker fit in about 2,900 lines of Rust with #![forbid(unsafe_code)] and zero third-party crates. Recursors are regenerated and checked, never taken from the export.
  • Lean's rules, not shortcuts. Large elimination, proof irrelevance, eta for functions and structures, unit-like types, Nat and string literals and eagerReduce follow Lean's own kernel.
  • Mutation testing. Exports are corrupted on purpose (swapped proofs, changed universes, broken definitions, altered inductive types) and re-checked. Across four rounds and 1,482 mutants, every change that alters meaning was rejected; the few accepted ones were provably harmless (for example outParam vs semiOutParam, which are the same function).
  • Fast without trusting more. Hash-consed expressions in 16-byte nodes, cached reduction and parallel checking of independent declarations; none of it adds rules to the kernel.
